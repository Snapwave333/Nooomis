NOOOMIS Tutorial
Learn the basics and discover advanced features
1
Basic Gameplay

Welcome to NOOOMIS! This is an enhanced Simon Says game where you need to repeat sequences of button presses.

How to play:

  • Watch the sequence of button flashes
  • Repeat the exact same sequence
  • Each successful round adds one more button
  • Make a mistake and you lose a life
💡 Tip: Pay attention to both the visual flash and the audio tone for each button.
2
Controls

NOOOMIS supports multiple input methods for accessibility:

Touch/Mouse:

  • Tap or click the colored buttons
  • Works on mobile devices and desktop

Keyboard:

  • Arrow Keys: ↑ Green, ↓ Red, ← Blue, → Yellow
  • WASD: W Green, A Red, S Blue, D Yellow
  • Number Keys: 1 Green, 2 Red, 3 Blue, 4 Yellow

Gamepad:

  • D-pad or face buttons (A, B, X, Y)
  • Automatically detected when connected
⚠️ Note: You can mix input methods during gameplay!
3
Game Modes

NOOOMIS features multiple game modes to keep things interesting:

Classic Mode: Traditional Simon Says with 3 lives

Speed Mode: Faster sequences with strict timing windows

Zen Mode: Relaxed pace with ambient music, no failure penalties

Chaos Mode: Button positions randomize each round

Advanced Modes: (Unlock with Memory Shards)

  • Mirror Mode: Input sequences in reverse order
  • Echo Mode: Audio-only sequences (no visual flashes)
  • Survival Mode: Endless rounds with random modifiers
  • Boss Mode: Periodic boss rounds with fake flashes
  • Liberation Mode: Pure experience (unlocked after meta arc)
4
Progression System

NOOOMIS features a rich progression system to keep you engaged:

Memory Shards:

  • Earn shards by reaching score milestones (10, 25, 50, 100, 200)
  • Complete daily challenges for bonus shards
  • Use shards to unlock themes, audio packs, and advanced modes

Daily Challenges:

  • Unique challenges with special modifiers
  • Reset daily at midnight UTC
  • Reward shards and exclusive unlocks

Unlock Shop:

  • Purchase themes, audio packs, and modes
  • Unlock lore fragments to learn the meta narrative
  • Access through the accessibility panel
💡 Tip: Check the shop regularly for new unlockable content!
5
Meta Arc Narrative

NOOOMIS features a unique fourth-wall breaking narrative that evolves as you play:

Session-Based Progression:

  • Phase 1 (Sessions 1-3): Subtle oddities begin
  • Phase 2 (Sessions 4-7): Escalation and corruption
  • Phase 3 (Sessions 8-12): Direct confrontation
  • Phase 4 (Sessions 13-15): Boss fight preparation
  • Phase 5 (Session 16+): Resolution and Liberation

What to Expect:

  • Random glitches and anomalies
  • Personalized messages based on your play style
  • UI corruption and impossible sequences
  • Multiple victory paths in the final boss fight
  • Liberation Mode as the ultimate reward
⚠️ Spoiler Warning: The meta arc is designed to be discovered naturally. Avoid spoilers for the best experience!
6
Accessibility Features

NOOOMIS includes comprehensive accessibility features:

Colorblind Support:

  • Pattern overlays: Green (dots), Red (stripes), Blue (crosshatch), Yellow (solid)
  • High contrast mode for better visibility

Timing Adjustments:

  • Adjustable input timing (0.5x to 2x multiplier)
  • Adaptive difficulty that adjusts to your performance

Feedback Options:

  • Vibration feedback for button presses
  • Audio cues for all visual elements
  • Multiple input methods (touch, keyboard, gamepad)

Accessibility Panel:

  • Access all accessibility features
  • Unlock shop and progression systems
  • Daily challenges and rewards
  • New Game+ features
💡 Tip: Experiment with different accessibility settings to find what works best for you!
