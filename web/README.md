# Legacy Web Prototype

This folder contains the original static HTML/CSS/JS prototype of NOOOMIS.

Active development has moved to the React client in:

- ../web-react (Vite + TypeScript)

What to use this for:
- Historical reference, quick comparisons, and asset inspiration
- Simple static hosting experiments

What not to use it for:
- New features or gameplay changes (these belong in web-react)

Quick run (optional):
- Serve this folder with any static server (e.g., `python -m http.server 5500`) and open `/web/`

Note: Audio/logic/UI here may be out of sync with the React client and is not the supported path for packaging or releases.
