# Contributing to NOMIS

Thanks for your interest! Here’s how to contribute effectively:

## Setup
- Unity 2021+ recommended for C# scripts
- Node.js 18+, Java JDK 17+, Android SDK for Android build scripts

## Workflow
1. Fork and create a feature branch
2. Run build scripts locally (web, android)
3. Add tests where applicable; keep PRs focused
4. Submit a PR with a clear description and screenshots for UI changes

## Code Style
- C#: follow existing patterns; avoid one-letter vars
- JS: modular, avoid global pollution; prefer `const/let`
- PowerShell: verbose logging; fail fast; no interactive prompts

## PR Checklist
- [ ] Linked issue
- [ ] Clear rationale and scope
- [ ] Screenshots for UI changes
- [ ] Passing builds locally

## Security
Report vulnerabilities privately via email or GitHub security advisories.
