# Release v2.1.0 — React Tutorial/Challenges, GameShell controls, audio packs, Android CI

Date: 2025-10-17

This release centers the React app (web-react) as the primary client, adds Tutorial and Challenges pages, introduces GameShell top controls and mode labels, and integrates audio packs with Cordova-friendly paths. The Android build script and CI now ensure web-react assets are always fresh.

## Highlights
- New pages: Tutorial and Challenges (Speed Up, Reverse)
- GameShell top bar with Back / Pause / Resume and mode label
- StartOptions for challenge modifiers (speedMultiplier, gapScale, reverse, startingLives)
- Audio packs selectable in Settings, persisted and applied at startup
- Android build script & CI integrate the React build automatically

## Full Changes (from CHANGELOG)

### Added
- React app (web-react) pages: Tutorial and Challenges
  - TutorialPage with interactive SimonBoard demo and basic instructions
  - ChallengePage with initial variants: Speed Up and Reverse
- GameShell top bar with Back, Pause, Resume controls and mode label
- Game modifiers via StartOptions in useGame: speedMultiplier, gapScale, reverse, startingLives
- Audio packs in the React app with sample-based playback and graceful oscillator fallback
- Settings page option to select audio pack; persisted and applied at startup
- Android build script now builds the React app and copies dist into Cordova www automatically
- Android CI workflow updated to build web-react and trigger on web-react/** changes

### Changed
- Audio sample path switched to relative web/assets/audio for compatibility with Cordova file://
- App wiring updated to pass mode labels and StartOptions to GameShell

### Fixed
- Audio pack loading under Cordova (file://) environments
- Minor navigation polish for Tutorial/Challenges flows

## Upgrade Notes
- Audio packs: place samples under `web-react/public/web/assets/audio/<PackName>/tone0.wav` through `tone3.wav`.
- Build (Android): use `tools/build_android.ps1`; it will build `web-react` and copy its `dist` into Cordova `www/` automatically.
- Build (Windows): use `tools/build_windows.ps1`; it packages Electron using the latest `web-react/dist`.
- Dev: `npm run dev` inside `web-react/` and open the Vite preview.
